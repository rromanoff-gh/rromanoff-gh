# Roman Romanov

Full-stack and frontend engineer working on 3D web maps, geospatial APIs, and browser audio. Currently building [atmoscheme.com](https://atmoscheme.com), an interactive 3D globe with live Open-Meteo weather, ambient audio, and guided tours.

Libraries extracted from Atmoscheme under MIT:

- [atmoscheme/cesium-scheme-preloader](https://github.com/atmoscheme/cesium-scheme-preloader): GLSL ENU grid and contour overlay for CesiumJS while globe tiles stream in
- [atmoscheme/cesium-tour-kit](https://github.com/atmoscheme/cesium-tour-kit): three-phase camera flights, Slippy-tile preloading, route slicing, and ocean shader styling for CesiumJS
- [atmoscheme/osm-ring-sampler](https://github.com/atmoscheme/osm-ring-sampler): concentric ring POI sampler (5 to 200 km) and track polyline stitcher over Overpass and Nominatim
- [atmoscheme/web-audio-sidechain](https://github.com/atmoscheme/web-audio-sidechain): Web Audio RMS sidechain ducking for background tracks under TTS and SpeechSynthesis
- [atmoscheme/piper-tts-nest-starter](https://github.com/atmoscheme/piper-tts-nest-starter): NestJS 11 and Docker Compose bridge for self-hosted Piper TTS with WAV caching
- [atmoscheme/vue-14seg](https://github.com/atmoscheme/vue-14seg): Vue 3 SVG 14-segment display with Unicode NFD diacritic folding and stepped animation

Day-to-day stack: TypeScript, Vue 3, CesiumJS, WebGL/GLSL, Web Audio API, Node.js, NestJS, Docker, Caddy.
